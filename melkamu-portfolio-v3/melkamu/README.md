# Melkamu Dejen — Personal Portfolio

A responsive, single-page personal portfolio created for the **Individual Assignment – Personal Website (Portfolio)**.

## Technologies
- HTML5 for semantic page structure
- CSS3 for responsive layout and visual styling
- JavaScript for interactive features

## Website sections
- Home
- About Me
- Technical Skills
- Projects
- Education
- Achievements
- Contact

## JavaScript interactions
1. Responsive mobile navigation menu
2. Dark/light theme toggle (preference saved in `localStorage`)
3. Project category filter
4. Contact form validation and email draft preparation
5. Automatically updated footer year

## Run the website
1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.
3. For local development, you may use the Live Server extension in Visual Studio Code.

No build tools or package installation are required.

## Important contact-form note
The contact form validates the visitor's input and opens their default email application using a `mailto:` link. It does **not** send or store messages on a server. A backend service would be needed for direct form submission.

## Personalization notes
The portfolio uses the details provided by Melkamu Dejen. Review every section before submission and make sure the descriptions accurately represent your own work. Add further project details only when you can explain and demonstrate them.

## Suggested testing
- Open the site on desktop and mobile screen sizes.
- Test every navigation link.
- Switch between dark and light themes and refresh the page.
- Test the project filter.
- Submit the contact form with empty fields, an invalid email, and valid details.
- Check the browser console for errors.
